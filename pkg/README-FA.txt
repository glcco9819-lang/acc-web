YFG ACC-WEB v1.4.0 — نسخهٔ وب ماژول حسابداری
=============================================================
نام‌گذاری دیتابیس — استاندارد تأییدشده:
  ACC  = حسابداری (جدول‌ها با پیشوند Acc:  ACC.AccVoucher / ACC.AccVoucherItm / ...)
  pob  = مشترک بین ماژول‌ها (pob.Companies / pob.Party / pob.FiscalYear / ...)
  YFG  = واژه‌نامهٔ دادهٔ سراسری (YFG.TableName / YFG.FieldName / YFG.LinkField)
کد هر ماژول جدید (انبار STR، فروش SLE، دریافت‌وپرداخت RAP، CRM و...) قبل از
پیاده‌سازی از کارفرما پرسیده و تأیید می‌شود. مستند کامل: docs/NAMING-RULES.md
=============================================================

تازه‌های v1.4.0 نسبت به 1.3.0:
  • فیلدهای ناقص سند (مصوب): ارز و نرخ (AccFx)، شعبه (AccBranch)، شمارهٔ پیگیری،
    شمارهٔ روز، شمارهٔ فرعی، شرح لاتین — در سرسند و قلم سند
  • سه جدول واژه‌نامهٔ داده: YFG.TableName (۳۶ جدول)، YFG.FieldName (۴۹۵ فیلد)،
    YFG.LinkField (۴۶ پیوند) — نام فارسی هر جدول/فیلد بر اساس نقش
  • پنجرهٔ «واژه‌نامهٔ داده» با سه برگه، جست‌وجو و خروجی اکسل
  • بازطراحی مدرن رابط کاربری (توکن‌های طراحی، کارت، برگه، ردیف بازشونده)
  • گزارش‌های تراز (v1.3.1): تراز کل/معین/تفصیلی، تراز ماهانهٔ ۱۲ ماه، شش‌ستونی
  • لاگ فعالیت کاربران در دیتابیس (pob.UserLog + تریگرهای ممیزی)
=============================================================

نصب روی سرور ویندوزی:
  1) این پوشه را در مسیری مثل C:\ACCWeb استخراج کنید
     (نصب اولیه یا ارتقا: پوشهٔ app قبلی جایش گرفته می‌شود)
  2) دیتابیس: اگر دیتابیس acc روی SQL Server همین سرور وجود ندارد،
     SETUP-ACC.cmd را اجرا کنید (رمز sa را می‌پرسد و دیتابیس + جدول‌ها + دادهٔ پایه را می‌سازد)
     — روی دیتابیس موجود، فقط فایل‌های 04 تا 06 پوشهٔ sql با sqlcmd اجرا شود
  3) START-ACC.bat را اجرا کنید — پنجرهٔ سرور باز می‌ماند
  4) مرورگر: http://localhost:5031
     (دسترسی از شبکه: بازکردن پورت 5031 در فایروال ویندوز)

کاربران نمونه (رمز همه: 1234):
  admin   — مدیر سامانه (قطعی/برگشت/تعاریف/آپدیت آنلاین)
  karbar1 — ثبت‌کنندهٔ اسناد (صدور سند/برگشت/تعاریف)
  karbar2 — بررسی‌کننده (بررسی/قطعی)

فرایند سند (مطابق اصلی): صدور ← بررسی ← قطعی — سند قطعی فقط با سند برگشتی اصلاح می‌شود.

آپدیت آنلاین (خودکار):
  هر ۱۵ دقیقه سرور ریلیز تازهٔ گیت‌هاب را بررسی می‌کند؛ اگر نسخهٔ بالاتری باشد
  بسته را دانلود و خودش را ری‌استارت می‌کند و راه‌انداز START-ACC بسته را نصب و
  دوباره بالا می‌آورد. همین مسیر از پنجرهٔ «آپدیت آنلاین» با ورود admin هم دستی قابل انجام است.

اتصال دیتابیس: app\db-config.json (پیش‌فرض: 127.0.0.1:1433 / acc / acc_app)
