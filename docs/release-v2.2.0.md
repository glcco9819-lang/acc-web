# v2.2.0 — ویرایش سند در همان پنجره + لیست اسناد + تاریخ‌های شمسی + پنجرهٔ تمام‌صفحه

این نسخه مستقیماً پنج بازخورد کارفرما را پیاده می‌کند.

## ۱) ویرایش سند در همان پنجرهٔ مرور حساب‌ها

- روی «مشاهدهٔ سند» در مرور حساب‌ها (و بررسی اسناد و لیست اسناد) دکمهٔ **«ویرایش سند»** اضافه شد
- ویرایشگر با همان ساختار «صدور سند»: سرسند (تاریخ/شرح/نوع/شعبه/ش روزانه/ش فرعي/لاتين) + ردیف‌ها (کل/معین/تفصیلی ۴-۵-۶/شرح/بدهکار/بستانکار) + ردیف بازشوندهٔ ارز و پیگیری
- API جدید `POST /api/vch/update` — اعتبارسنجی مشترک با صدور (`lib/vchitems`): کدینگ، تفصیلی‌های الزامی، ارز سه‌تایی، تراز
- فقط اسناد **موقت/بررسی‌شده** ویرایش می‌شوند؛ سند **قطعی** باید اول برگشت داده شود؛ اسناد برگشتی و اسناد ماژول‌های دیگر غیرقابل ویرایش‌اند
- هر ویرایش در ردپای عملیات با اکشن «ویرایش» ثبت می‌شود
- پس از ذخیره، گردش حساب و سند نمایش‌داده‌شده بلافاصله به‌روز می‌شوند

## ۲) پنجرهٔ جدید «لیست اسناد» (درخواست: «در اسناد گزینه لیست اسناد وجود ندارد»)

- منوی «اسناد حسابداری ← لیست اسناد»
- فیلترها: وضعیت (موقت/بررسی‌شده/قطعی)، بازهٔ تاریخ جلالی، بازهٔ شمارهٔ سند، نوع سند، جست‌وجوی شرح
- عملیات: مشاهده (دوبار کلیک روی ردیف)، ویرایش، خروجی Excel
- API فهرست با فیلترهای تاریخ/نوع تکمیل شد

## ۳) پنجره‌ها کل صفحه را پر می‌کنند + قابل بزرگ/کوچک شدن

- قاب پنجره در حالت پیش‌فرض تمام‌صفحه است (ارتفاع کامل viewport، جدول‌ها تا انتهای پنجره کشیده می‌شوند)
- دکمهٔ «❐/▣» روی نوار عنوان پنجره: جابه‌جایی میان تمام‌صفحه و حالت پنجره‌ای
- در حالت پنجره‌ای، پنجره با موس (گوشهٔ پنجره) قابل تغییر اندازه است؛ انتخاب کاربر به‌خاطر سپرده می‌شود

## ۴) ستون‌های «صدور سند» قابل تغییر اندازه با موس

- دستگیرهٔ باریک در لبهٔ هر ستون — با کشیدن موس عرض ستون بزرگ/کوچک می‌شود
- همان قابلیت در ویرایشگر سند نیز فعال است

## ۵) تاریخ‌های سیستم شمسی شدند («تاریخ ها شمسی نیستند»)

- زمان «ردپای عملیات» سند که میلادی نمایش داده می‌شد، اکنون **جلالی با ساعت تهران** است (مثل `1405/08/07 14:30`)
- زمان‌های ثبت/بررسی/قطعی سرسند نیز شمسی برمی‌گردند
- تبدیل سراسری در `lib/jalali.faDateTime` — مبنا: UTC سرور +۳:۳۰ تهران

## زیرساخت

- اعتبارسنجی اقلام سند به ماژول مشترک `lib/vchitems.ts` منتقل شد (صدور و ویرایش یک منطق واحد)
- **رفع بن‌بست تراکنش در `vch/update`**: خواندن سند از pool دیگر داخل تراکنشِ قفل‌شده باعث تعلیق همیشگی درخواست می‌شد — خواندن نهایی به پس از commit منتقل شد (تست دودی کامل: صدور→ویرایش→راستی‌آزمایی→پاک‌سازی)
- CSS: چیدمان تمام‌ارتفاع (`flex`)، اسکرول داخل قاب اصلی، استایل پنجره‌ای قابل resize، استایل دستگیرهٔ ستون‌ها، چاپ بدون تغییر رفتار
