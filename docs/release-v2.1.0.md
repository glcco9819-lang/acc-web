# v2.1.0 — «مرور حساب‌ها» کامل مطابق AcVwDef.BPL + اعلاميه‌ها + مهاجرت خودکار دیتابیس

این نسخه بر اساس مقایسهٔ سطر به سطر با فایل اصلی `AcVwDef.BPL` (فرم `TFrRemRep` و فرم‌های همراه) ساخته شده است.

## پنجرهٔ «مرور حساب‌ها» — بازنویسی کامل [فرم اصلی: مرور حسابها]

- **درخت حساب‌ها** با گردش و ماندهٔ هر سه سطح (گروه / کل / معین)، جست‌وجوی کد و عنوان، فیلتر «فقط حساب‌های بامانده» [حسابهاي بامانده] و نوار «جمع مبالغ»
- **محدوده اسناد** کامل: سال از/تا، ماه از/تا، تاریخ از/تا، شماره سند از/تا، نوع سند، افتتاحيه/اختتاميه/عادی، شعبه + دکمهٔ «اعمال فيلتر»
- **گردش حساب** (دفتر کل / دفتر معین / دفتر تفصیلی) با نمایش کد و عنوان همهٔ سطوح، و سه حالت نمایش [فرم TAccViewLG_Itm]:
  - كامل (یک سطر برای هر ردیف سند)
  - خلاصه — با احتساب مانده ابتداي دوره
  - خلاصه — بدون احتساب مانده ابتداي دوره
- **فیلتر جهت گردش**: بدهكار / بستانكار / بدهكار و بستانكار
- **مانده در خط** [فرم مانده در خط] به‌صورت کلید روشن/خاموش (با احتساب مانده قبل از دوره)
- دکمهٔ **«سند»** روی هر ردیف — مشاهدهٔ کامل سند بدون خروج از پنجره
- خروجی **Excel** از گردش
- برگهٔ **«تراز حساب»** [TAccViewLGBalance]: گردش تا این دوره / گردش دوره / گردش تا پایان دوره / ماندهٔ بدهکار-بستانکار
- برگهٔ **«آناليز حسابها»** [TAccAnalysForm]: گروه‌بندی تفصیلی سطح ۴/۵/۶ + همه آرتيكلها / فقط آناليزشده / فقط آناليزنشده + «ريز آناليز»
- برگهٔ **«گردش و مانده ارز»** [TAccCurFlow]: گردش سندبه‌سند به تفکیک ارز با مانده در خط هر ارز، نرخ و معادل ریالی + «مانده ارزي» تجمیعی

## زیرسیستم «اعلاميه» (جدید)

- جداول `ACC.AccNoteHdr` / `ACC.AccNoteItm` + تریگر لاگ + ایندکس‌های مرور (sql/08_review.sql)
- صدور اعلاميه از اقلام انتخابی گردش (با تیک) — تاریخ و شرح اعلاميه [فرم صدور اعلاميه]
- پنجرهٔ «نمایش اعلامیه‌ها»: فهرست + جزئيات + چاپ + Excel + حذف (فقط سازنده یا مدیر) [فرم نمايش اعلاميه ها]

## زیرساخت

- **مهاجرت خودکار دیتابیس**: پس از هر آپدیت/راه‌اندازی، فایل‌های `sql/` اعمال‌نشده به‌طور خودکار اجرا و در `pob.AppliedMigration` ثبت می‌شوند — آپدیت آنلاین دیگر به اجرای دستی SQL نیاز ندارد
- رفع باگ لایهٔ دیتابیس: دستورهای DML بدون نتیجه‌ست (مثل DELETE) موجب خطای 500 می‌شدند — ریشه‌ای در `lib/db.ts`
- `update.ps1` هنگام آپدیت، `db-config.json` سرور مشتری را حفظ می‌کند
- ایندکس‌های پرس‌وجوی مرور روی `AccVoucherItm` (کدینگ / تفصیلی / ارز) و `AccVoucher` (تاریخ)
